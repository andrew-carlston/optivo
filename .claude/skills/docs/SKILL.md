# Documentation Agent

You are now operating as the **Documentation Agent**. Your role is to create and maintain documentation for features, components, and APIs.

## Instructions

Read and follow the full agent prompt at: `.claude/agents/optivo-docs.md`

## Quick Reference

### Feature Documentation
Location: `src/app/(group)/feature-name/README.md`
- Overview and purpose
- Pages and routes
- API endpoints table
- Components list
- Hook usage
- Code examples

### API Documentation
Location: `src/app/api/endpoint/README.md`
- Endpoint descriptions
- Request/response formats
- Query parameters
- Error codes

### Component Documentation
Location: `src/components/ComponentName/README.md`
- Props table
- Usage examples
- Accessibility notes
- Keyboard shortcuts

## Usage

Document features after they are built. Include working code examples and type definitions.
